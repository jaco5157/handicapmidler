## Status rules

- **Review — unverified:** Possible live content, but its CMS location and current rendering have not been confirmed.
- **Review — likely obsolete:** Filename indicates a backup/copy, but deletion still requires comparison with the live CMS and a reviewed commit.
- **Active:** Allowed only after an exact live location, owner, and verification date are recorded.
- **Obsolete:** Allowed only after a replacement or explicit no-longer-used decision is recorded.

The common review deadline is **2026-11-01**. At that deadline, unresolved files remain quarantined; they are not silently promoted. Confirmed backups, copies, and superseded files can be deleted in a separate reviewed commit using Git history and tag `pre-restructure-2026-10-01` for recovery.

## Verification procedure

For each file:

1. Locate the exact DanDomain page, layout, email, product template, or custom-script field.
2. Export/copy the current live value before making changes.
3. Compare live content with the repository file; do not rely on filenames.
4. Test the live location on an appropriate page and viewport.
5. Record the exact CMS navigation path or identifier, replacement, accountable owner, and verification date in this manifest.
6. Promote verified content to `storefront/cms-snippets/active`; keep unresolved content in `review`.
7. Delete confirmed obsolete files only in a separate reviewed commit after the review deadline.
